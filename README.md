# Machine Learning Lab Assignments

A comprehensive collection of machine learning assignments implementing fundamental and advanced algorithms, demonstrating proficiency in supervised learning, unsupervised learning, and ensemble methods.

## Overview

This repository contains hands-on implementations of core machine learning concepts and algorithms, with a focus on understanding algorithm mechanics and evaluating model performance.

## Assignments

### Assignment 1: Data Preprocessing and Exploratory Data Analysis
Introduction to data handling, cleaning, and visualization techniques to prepare datasets for machine learning models.

### Assignment 2: Classification Algorithms - KNN and Naive Bayes
Implementation and comparison of k-Nearest Neighbors and Naive Bayes classifiers, including evaluation metrics and performance analysis.

### Assignment 3: Decision Tree Classifier
Development and optimization of decision tree models with insights into feature importance and tree-based decision-making.

### Assignment 4: Support Vector Machine (SVM) Classifier
Implementation of SVM classifier with comprehensive comparison against decision tree models, including kernel methods and hyperparameter tuning.

### Assignment 5: Ensemble Methods
Exploration of ensemble techniques including bagging, boosting, and stacking to improve model performance and robustness.

### Assignment 6: Clustering Techniques
Implementation of various clustering algorithms (K-means, hierarchical clustering, DBSCAN, etc.) with performance evaluation and visualization.

### Assignment 7: Regression Techniques
Development and evaluation of regression models including linear regression, polynomial regression, and advanced regression methods.

## Technology Stack

- **Language**: Python
- **Primary Format**: Jupyter Notebooks
- **Libraries**: scikit-learn, pandas, NumPy, Matplotlib, Seaborn

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/spandansudame/ML-Lab-Assignments.git
   cd ML-Lab-Assignments
   ```

2. Install required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Open Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
